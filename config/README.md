# 配置目录说明

本目录是第一阶段 Demo 的主要数据替换入口。Demo 不连接真实设备，修改配置后重新启动开发服务或重新构建即可生效。

## 文件

- `project.json`：项目名称、场馆名称、英文名、版本和主题色。
- `platform.json`：告警、工单、人员、访客、车辆、发布屏、地图节点、动环、UPS、背景音乐、无线 AP、接口和演示场景。
- `../public/config/cameras.json`：摄像头、楼层、视频状态和录像片段。

## 替换原则

1. 保留每条数据的字段名，只修改字段值或增删完整记录。
2. 所有 `id` 在同类数据中必须唯一；关联字段应使用已有设备或业务编号。
3. 地图点位 `x`、`y` 使用 0–100 的相对坐标，底图更换后无需修改页面代码。
4. 客户资料暂缺时保留示例记录，不要删除整个数组，确保页面仍可完整演示。
5. `dataMode` 在第一阶段必须保持 `mock`。
6. `systemInterfaces` 只描述拟接入方式，第一阶段适配器名称保持 `Mock...Adapter`，不得填写“已联调”。

## 快速检查

修改后执行：

```bash
npm run validate:config
npm run build
```

若浏览器保留了之前操作后的状态，可在“演示控制台”点击“重置全部演示数据”。
