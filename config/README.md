# 配置目录说明

本目录是平台数据与现场清单的主要替换入口。当前前端不直接连接现场设备；收到厂家接口资料后，应优先增加适配器并继续沿用现有标准数据模型。

## 文件

- `project.json`：项目名称、场馆名称、英文名、版本和主题色。
- `platform.json`：告警、工单、人员、访客、车辆、发布屏、地图、动环、UPS、背景音乐、无线 AP、接口和验证场景。
- `public.json`：公众展示入口的展览、活动、服务和开放信息。
- `backend.json`：现场设备资产、硬件协议、外部系统、展示渠道、开放 API 和操作日志。
- `field-data.json`：由现场表格脱敏整理的 VLAN、地址分配与舞台灯光配置。
- `../public/config/cameras.json`：112 路现场摄像头的编号、楼层、位置、IP 和视频资源配置。

## 当前现场数据覆盖

- 摄像头 112 路：B1F 37 路、1F 北馆 49 路、1F 南馆 26 路。
- 通行相关设备 150 台。

- UPS 7 台、背景音乐设备 18 台、发布屏 2 台。

## 替换原则

1. 保留字段名，只修改字段值或增删完整记录；同类数据的 `id` 必须唯一。
2. 地图 `x`、`y` 使用 0–100 的相对坐标，替换底图不要求修改页面代码。
3. 现场资料尚未提供的业务记录保留可替换配置，避免页面出现空模块。
4. 视频素材未提供时保持 `videoUrl: null`，页面展示资源待配置状态。
5. 现场原表中的账号、密码、口令、Token、MAC 和序列号等敏感字段不得写入公开仓库或浏览器配置。
6. `配置就绪` 仅表示配置已加载，不代表 SDK、GB/T 28181、门禁、动环、UPS 或其他厂家接口已经联调。

## 快速检查

修改后执行：

```bash
npm run check
```

技术后台使用带版本的 LocalStorage 键。配置结构版本变化时更新 `config/backend.json` 的 `schemaVersion`，浏览器会自动加载新的配置基线。
